# 🖼️ Gallery House

> A modern, elegant online art gallery built with **React**, **TypeScript**, **Tailwind CSS**, and **Mantine UI**.

Gallery House is a responsive web application for discovering, exploring, and showcasing artwork in a clean, museum-inspired digital experience. The project emphasizes modern frontend architecture, reusable components, accessibility, and scalable development practices.

---

## ✨ Features

### 🎨 Art Gallery

- Browse artworks in a responsive gallery
- Artwork detail pages
- Featured collections
- Categories and artists
- Search and filtering
- Responsive masonry/grid layouts

### 👤 User Experience

- Authentication
- User profile
- Favorites
- Shopping cart
- Checkout flow
- Dark and light themes

### 📊 Dashboard

- Upload artwork
- Manage artworks
- Orders
- Account settings

### ⚡ Performance

- Lazy loading
- Image optimization
- Code splitting
- SEO-friendly pages
- Accessibility (WCAG)

# 🚀 Getting Started

## Prerequisites

- Node.js 22+
- npm (or pnpm/yarn)
- Git

## Installation

Clone the repository:

```bash
git clone https://github.com/Nirush4/gallery_house
```

Navigate to the project:

```bash
cd gallery-house
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser at:

```text
http://localhost:5173
```
